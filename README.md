# AI Native SaaS Data Analysis

基于 Python、DuckDB、Pandas 和 LLM 的 AI 辅助数据分析及报告质量评估项目。

## 1. 项目简介

本项目围绕模拟 SaaS 业务数据，构建从业务问题到 SQL 查询、数据质量校验、分析结果导出及 AI 报告评估的工作流程。

项目重点是验证数据分析结果的准确性、识别 AI 报告中的数据幻觉，并控制无依据的业务归因。

## 2. 技术栈

- Python
- DuckDB：SQL 查询与数据分析
- Pandas：数据处理与独立指标核验
- SQLGlot：SQL 结构解析及基础访问约束
- LLM：辅助生成 SQL、业务报告及语义评估判断

## 3. 项目功能

### 数据质量检查

- 检查三表 JOIN 后的订单粒度
- 检查未匹配用户及产品
- 通过 SQL/Pandas 双重计算核验月度指标

### AI SQL 分析

- 根据数据字典和 Prompt 辅助生成 DuckDB SQL
- 使用 SQL Guard 检查查询结构
- 限制数据库的外部文件访问
- 对查询结果执行已知基线校验
- 导出渠道收入分析结果

### AI 报告评估

- 验证渠道金额和收入占比
- 检查报告渠道遗漏及重复
- 构建数值测试集和人工标准标签
- 使用 LLM 评委判断事实一致性及因果归因
- 计算 Accuracy、Precision、Recall、FPR

## 4. 数据说明

使用三张模拟业务表：

- orders：240 条订单
- users：80 名用户
- products：4 个产品

已验证的基线指标：

- 成功支付订单数：184
- 总收入：64,471
- 全期间去重付费用户：72
- 2026 年 4 月收入：31,292

## 5. 环境要求

推荐 Python 3.11。

安装依赖：

```bash
python -m pip install -r requirements.txt
```

## 6. 运行方式

在项目根目录执行：

```bash
python main.py
```

程序依次执行数据质量检查、SQL 分析、数值评估及已保存预测结果的离线评估。

分析结果保存在 `output/` 目录中。

## 7. 已完成的测试

- 单渠道数值测试：7/7
- 完整报告表格测试：5/5
- LLM 评委基础案例：4/4
- LLM 评委新增案例：6/6

上述结果只针对当前有限测试集，不代表真实线上数据或大规模评估表现。

## 8. 系统边界

本项目目前属于学习与研究原型。

- LLM 生成 SQL 和报告的步骤仍包含人工操作，尚未接入自动模型 API。
- SQL Guard 并非生产级安全沙箱。
- 语义评估基于少量人工标注案例。
- 缺少真实营销成本及实验增量数据，不能据此判断渠道 ROI 或因果效果。
